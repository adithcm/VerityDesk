# Milestone 5.3: Daily Briefing Generator

Status: Planned

## Goal

Generate a daily briefing from current ingested evidence and relevant specialist agents.

## Deliverables

- Daily briefing report template.
- Evidence selection for world news, markets, macro, company, housing, and risk signals.
- Natural-language briefing synthesis.
- Required disclaimer, citations, risks, and uncertainty sections.
- Manual daily briefing generation endpoint.
- Tests for grounded generation and guardrail behavior.

## Definition Of Done

- A user can generate a daily briefing from the backend.
- The briefing cites source-backed evidence and avoids direct investment advice.
- Thin-data cases clearly state uncertainty.
