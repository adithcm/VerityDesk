# Milestone 5.2: Evidence Cleanup And Source Data Quality

Status: Planned

## Goal

Improve the quality of source data shown to users and passed into reports, especially economic observations from official APIs.

## Deliverables

- Friendly labels for FRED series IDs such as `UNRATE`, `FEDFUNDS`, and `MORTGAGE30US`.
- Grouping logic so repeated economic observations do not dominate the UI or generated reports.
- Clear separation between news/article evidence and structured economic data.
- Evidence metadata that explains published, released, and retrieved timestamps.
- Tests for labels, grouping, and mixed evidence packages.

## Definition Of Done

- Users no longer see raw series IDs as the main label when a friendly name is available.
- Report builders can request grouped article and economic evidence.
- Evidence packages are readable before they are sent to the LLM.
