# Milestone 5.6: Housing And Macro Reports

Status: Complete

## Goal

Generate housing and macro reports that combine news, rates, labor, credit, mortgage, and housing data.

## Deliverables

- Housing report generation endpoint and dashboard action.
- Macro report generation endpoint and dashboard action.
- Agent-backed evidence selection across housing, macro, markets, credit, consumer, labor, and policy domains.
- Required recency, uncertainty, and risk framing in generated prompts and report metadata.
- Tests for housing and macro report creation, metadata, citations, and API endpoints.

## Implementation Notes

- Housing reports use the `housing_macro_research` route and ask for mortgage rates, affordability, prices, supply, demand, construction, credit conditions, and risks.
- Macro reports use the same route and ask for rates, labor, price-pressure context, policy signals, credit conditions, broad risks, and watch items.
- Generated reports are persisted through the existing report model with citation records, guardrail status, confidence, agents run, follow-up questions, and risk metadata.
- The dashboard now includes Housing Report and Macro Report buttons with compact saved-report previews and citation panels.

## Definition Of Done

- A user can generate housing and macro reports.
- Official economic observations are labeled clearly and grouped cleanly through the Phase 5 evidence cleanup path.
- The report states data recency and uncertainty.
- Housing and macro report generation is covered by backend tests.
