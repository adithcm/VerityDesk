# Milestone 5.7: Report Persistence And Citation Panels

Status: Complete

## Goal

Make generated reports durable and easy to review in the UI with citations attached to each report.

## Deliverables

- Saved reports list in the UI.
- Report detail view with report body, status, confidence, guardrail state, generated date, and context metadata.
- Citation panel with source, URL, published/released date, retrieved date, and support text.
- Report regenerate action that creates a fresh saved report from the original report context.
- Archive and delete actions.
- Tests for active report listing, archive behavior, and regeneration context.

## Implementation Notes

- The Reports tab loads active saved reports from `GET /api/v1/reports`.
- Archived reports are hidden from the active reports list but remain retrievable by direct report ID.
- Regeneration uses the saved report's type, domains, tickers, companies, regions, time window, and original user query where available.
- Delete permanently removes a report and its citations.
- Generated reports from Daily Briefing, Watchlist, Market Strategy, Housing, and Macro now refresh the saved reports list automatically.

## Definition Of Done

- Reports remain available after app restart.
- Users can inspect the sources behind a report.
- Citation metadata is preserved with the saved report.
- Users can regenerate, archive, or delete saved reports from the UI.
