# Milestone 5.7: Report Persistence And Citation Panels

Status: Planned

## Goal

Make generated reports durable and easy to review in the UI with citations attached to each report.

## Deliverables

- Saved reports list.
- Report detail view.
- Citation panel with source, URL, published/released date, retrieved date, and support text.
- Report refresh/regenerate action.
- Delete/archive action.
- Tests for report retrieval and citation display data.

## Definition Of Done

- Reports remain available after app restart.
- Users can inspect the sources behind a report.
- Citation metadata is preserved with the saved report.
