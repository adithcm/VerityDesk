# Milestone 5.8: Proactive Briefing Suggestions

Status: Planned

## Goal

Make the agent experience feel less manual by suggesting useful briefings and follow-up questions based on recent data, preferences, and watchlist context.

## Deliverables

- Preference-aware briefing defaults.
- Watchlist-aware suggested questions.
- Suggested daily context before the user asks a free-form question.
- Follow-up prompts generated from recent evidence and report gaps.
- UI surface for suggested questions and recommended report types.
- Tests for deterministic suggestion inputs and safe output constraints.

## Definition Of Done

- The app can show useful suggested questions or briefings without starting from a blank query box.
- Suggestions are grounded in saved preferences, watchlist items, and recent ingested evidence.
- Investment guardrails apply to proactive suggestions.
