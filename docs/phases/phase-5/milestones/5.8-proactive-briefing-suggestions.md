# Milestone 5.8: Proactive Briefing Suggestions

Status: Complete

## Goal

Make the agent experience feel less manual by suggesting useful briefings and follow-up questions based on recent data, preferences, and watchlist context.

## Deliverables

- Preference-aware briefing defaults using current saved report context and watchlist defaults.
- Watchlist-aware suggested questions.
- Suggested daily context before the user asks a free-form question.
- Follow-up prompts generated from recent evidence, saved reports, and report gaps.
- UI surface for suggested questions, recommended report types, and evidence coverage checks.
- Tests for deterministic suggestion inputs and safe output constraints.

## Implementation Notes

- Added `GET /api/v1/suggestions/proactive`.
- Suggestions are deterministic and use recent articles, recent official economic observations, active saved reports, and default watchlist context.
- The Dashboard now shows Suggested Next Steps cards with report, question, and evidence-gap suggestions.
- Suggested question cards prefill Agent Chat and choose a reasonable intent/domain.
- Suggested report cards can trigger Daily Briefing, Market Strategy, Housing, or Macro report generation.
- Each suggestion carries the standard research-only guardrail note.

## Definition Of Done

- The app can show useful suggested questions or briefings without starting from a blank query box.
- Suggestions are grounded in saved preferences, watchlist items, and recent ingested evidence.
- Investment guardrails apply to proactive suggestions.
