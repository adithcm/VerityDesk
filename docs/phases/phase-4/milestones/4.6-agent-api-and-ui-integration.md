# Milestone 4.6: Agent API And UI Integration

Status: Planned

## Goal

Connect the new agent framework to the backend API and frontend agent workspace.

## Deliverables

- Backend endpoint wired to the real coordinator.
- Agent run history available through API.
- Frontend agent chat uses real agent outputs.
- UI shows agents run, confidence, citations, risks, and guardrail status.
- Loading, empty, and missing-data states.
- Tests for endpoint behavior and frontend type safety.

## Definition Of Done

- The Agent Chat view no longer returns placeholder-only responses.
- Users can see why an answer was generated and what sources supported it.
