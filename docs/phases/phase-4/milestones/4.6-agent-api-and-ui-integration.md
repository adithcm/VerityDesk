# Milestone 4.6: Agent API And UI Integration

Status: Complete

## Goal

Connect the new agent framework to the backend API and frontend agent workspace.

## Deliverables

- Backend endpoint wired to the real coordinator.
- Agent run history available through API.
- Frontend agent chat uses real agent outputs.
- UI shows agents run, confidence, citations, risks, and guardrail status.
- Loading, empty, and missing-data states.
- Tests for endpoint behavior and frontend type safety.

## Implemented

- Added `GET /api/v1/agents/runs`.
- Added agent run history response schemas.
- Added backend service helper for reading recent agent runs.
- Updated frontend agent response typing for claims, citations, guardrail issues, and rewritten text.
- Added frontend loading for recent agent runs.
- Added agent intent selection to the Agent Chat form.
- Updated Agent Chat to show real multi-agent response details:
  - agents run
  - confidence
  - citation count
  - review-needed state
  - structured claims
  - citations with source, URL, published date, and retrieved date
  - risks
  - follow-up questions
  - guardrail status and issues
- Updated the sidebar phase badge to `Phase 4.6`.
- Added tests for agent run history behavior.

## Definition Of Done

- The Agent Chat view no longer returns placeholder-only responses.
- Users can see why an answer was generated and what sources supported it.

## Validation Results

- Backend tests passed: 79 passed.
- Backend lint passed.
- Frontend typecheck passed.
- Frontend production build passed.
- Local frontend smoke check returned HTTP 200.
- Agent run history endpoint returned recent agent runs.

## Notes

- The Agent Chat view now exposes the multi-agent backend output, but visual polish remains intentionally minimal until Phase 6.
- Agent run history is read-only in this milestone.
