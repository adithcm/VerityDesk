# Milestone 4.1: Agent Runtime Foundation

Status: Complete

## Goal

Create the shared runtime foundation that all research agents will use.

## Runtime Flow

```mermaid
sequenceDiagram
    participant UI as Frontend Agent Chat
    participant API as /api/v1/agents/query
    participant Runtime as AgentRuntime
    participant Registry as AgentRegistry
    participant Logger as AgentRunLogger
    participant Agent as CoordinatorAgent
    participant DB as agent_runs

    UI->>API: Submit AgentQueryRequest
    API->>Runtime: Run CoordinatorAgent with AgentContext
    Runtime->>Registry: Resolve agent by name
    Runtime->>Logger: Record running state
    Logger->>DB: Insert agent run
    Runtime->>Agent: Execute shared run contract
    Agent-->>Runtime: Return AgentResult
    Runtime->>Logger: Record success output
    Logger->>DB: Update agent run
    Runtime-->>API: Return AgentResult
    API-->>UI: Return AgentQueryResponse
```

```mermaid
classDiagram

    class BaseAgent {
        name
        run(context)
    }
    class AgentRegistry {
        register(agent)
        get(agent_name)
        names()
    }
    class AgentRuntime {
        run(agent_name, context)
    }
    class AgentRunLogger {
        start(context, agent_name)
        complete(run, result)
        fail(run, error)
    }

    BaseAgent --> AgentContext
    BaseAgent --> AgentResult
    AgentRuntime --> AgentRegistry
    AgentRuntime --> AgentRunLogger
    AgentRuntime --> BaseAgent
```

## Deliverables

- Agent request and response schemas.
- Shared agent context object.
- Agent result object with confidence, risks, citations, and follow-up questions.
- Base agent interface.
- Agent registry.
- Agent run logging service foundation.
- Tests for schema validation and base runtime behavior.

## Implemented

- Added `AgentContext` and `AgentResult` schemas.
- Added `BaseAgent` runtime protocol.
- Added `AgentRegistry` for deterministic agent registration and lookup.
- Added `AgentRuntime` for invoking registered agents through a shared contract.
- Added `AgentRunLogger` for recording running, success, and failed agent runs using the existing `agent_runs` table.
- Updated the placeholder coordinator to run through the runtime foundation.
- Updated the agent query endpoint to provide a database session for run logging.
- Added tests for context construction, registry behavior, runtime success logging, and runtime failure logging.
