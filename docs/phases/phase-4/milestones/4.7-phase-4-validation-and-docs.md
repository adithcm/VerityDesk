## Agent Query Checklist

- Coordinator runtime is active behind `/api/v1/agents/query`.
- Deterministic routing selects specialist agents by intent, domains, tickers, companies, regions, and query keywords.
- Domain agents can return source-backed partial findings when evidence exists.
- Missing-data paths return low-confidence responses instead of inventing facts.
- Agent runs are logged and readable through `/api/v1/agents/runs`.
- Final responses are presented as natural-language synthesis first, with structured claims, citations, risks, and guardrail details retained as support.

## Guardrail Checklist

- Financial disclaimer is required for investment-oriented outputs.
- Direct buy/sell/hold language is detected.
- Guaranteed-return and risk-free language is detected and rewritten.
- Unsupported price-target wording is flagged.
- Low-confidence responses are marked for review.
- Investment-oriented responses without citations are marked for review.

## Citation Review

- Citations include source ID, title, URL when available, publisher/source, published date, retrieved date, and supporting-claim text.
- Synthesized responses include a sources section.
- Duplicate citations are removed before returning the final response.
