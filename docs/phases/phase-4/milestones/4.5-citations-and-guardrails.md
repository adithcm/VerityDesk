# Milestone 4.5: Citations And Guardrails

Status: Complete

## Goal

Make agent responses source-grounded and safe for investment-adjacent use.

## Deliverables

- `CitationAgent` or citation enrichment service.
- Citation formatting with source name, URL, published date, and retrieved date.
- `RiskGuardrailAgent` integration.
- Explicit citation and guardrail prompt/rule templates.
- Required disclaimer for investing-oriented outputs.
- Checks that block direct buy/sell instructions, guaranteed-return language, and unsupported price targets.
- Tests for citation coverage and guardrail enforcement.

## Implemented

- Added citation formatting service.
- Added sources section formatting for synthesized agent responses.
- Extended `AgentCitation` with `published_at` and `retrieved_at`.
- Extended guardrail output with optional rewritten safe text.
- Added response-level guardrail enforcement after synthesis.
- Added direct buy/sell/hold advice rewrite handling.
- Added guaranteed-return and risk-free wording rewrite handling.
- Added unsupported price-target detection.
- Added no-citation detection for investment-oriented responses.
- Added low-confidence uncertainty enforcement.
- Updated final agent response builder to use rewritten safe text when guardrails require it.
- Added tests for citation formatting, missing citations, direct advice blocking, low-confidence handling, unsupported price targets, and rewritten summaries.

## Definition Of Done

- Investment-related answers include disclaimers and risk framing.
- Responses cite their evidence.
- Unsafe recommendations are blocked or rewritten.

## Validation Results

- Backend tests passed: 77 passed.
- Backend lint passed.

## Notes

- Guardrail checks are rule-based and deterministic.
- Responses with blocked wording still return a response object, but `requires_guardrail_review` is set to `true`.
- More UI visibility for citations, guardrail issues, and rewritten text is planned for Milestone 4.6.
