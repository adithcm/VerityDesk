# Milestone 4.2: Research Data Access Layer

Status: Complete

## Goal

Give agents a clean way to retrieve relevant ingested articles, source health, economic observations, and recent run metadata.

## Deliverables

- Query helpers for latest articles by domain, source, ticker, and time window.
- Query helpers for economic observations by series/source.
- Query helpers for source health and freshness.
- Lightweight ranking/filtering for candidate evidence.
- Tests for data retrieval and filtering behavior.

## Implemented

- Added `ResearchEvidenceRepository`.
- Added `EvidenceQuery` for domain, source, ticker, company, region, series, time window, and limit filters.
- Added citation-ready evidence objects for articles, economic observations, source health, and ingestion runs.
- Added latest article retrieval with domain, source, ticker, company, region, and time-window filtering.
- Added economic observation retrieval with source, series, region, and time-window filtering.
- Added source health retrieval for agents.
- Added recent ingestion run retrieval for agents.
- Added lightweight relevance scoring so stronger domain/ticker/company matches rank first.
- Added tests for article filtering, time-window exclusion, economic observation filtering, source health retrieval, and ingestion run retrieval.

## Definition Of Done

- Agents can ask for relevant evidence without querying database models directly.
- Returned evidence includes enough metadata for citations.
