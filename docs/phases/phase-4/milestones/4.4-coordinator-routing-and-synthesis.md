# Milestone 4.4: Coordinator Routing And Synthesis

Status: Complete

## Goal

Build the coordinator that decides which agents should run and combines their outputs into one answer.

## Deliverables

- Intent and domain routing logic.
- Ticker/company/region extraction support.
- `CoordinatorAgent`.
- Multi-agent fan-out and result collection.
- Synthesis layer for combining domain agent outputs.
- Coordinator synthesis prompt template.
- Tests for routing and synthesis behavior.

## Implemented

- Added deterministic coordinator routing from request intent, domains, tickers, companies, regions, and query keywords.
- Routed company/ticker queries to `CompanyAgent`.
- Routed market/rates queries to `MarketAgent`.
- Routed macro/economy/labor/Fed queries to `MacroAgent`.
- Routed housing/mortgage/real estate queries to `HousingAgent`.
- Routed news/briefing/world-update queries to `NewsDigestAgent`.
- Added fallback routing to `NewsDigestAgent` and `MarketAgent` for broad general requests.
- Updated `/api/v1/agents/query` to run the coordinator and selected specialist agents through `AgentRuntime`.
- Added synthesis that combines specialist summaries into one guarded response.
- Preserved specialist claims, citations, risks, follow-up questions, and confidence in the final response.
- Added citation and risk deduplication.
- Added tests for endpoint routing, housing macro routing, general fallback routing, and synthesis output.

## Definition Of Done

- A user query triggers the right subset of agents.
- Combined responses preserve risks, citations, and confidence.

## Validation Results

- Backend tests passed: 71 passed.
- Backend lint passed.

## Notes

- Routing is intentionally deterministic so repeated queries choose the same agents.
- Synthesis is currently template-based. More explicit synthesis prompt templates and citation/guardrail refinement continue in Milestone 4.5.
