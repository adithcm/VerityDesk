# Milestone 6.4: Cleaner Report And Briefing Views

Status: Complete

## Goal

Make Daily Briefing and Reports feel like readable intelligence products instead of raw output dashboards.

The user should see the answer first. Source details, metadata, and raw inputs should stay available without dominating the screen.

## Implemented Changes

- Simplified Daily Briefing into a single reading-focused view.
- Moved raw briefing inputs behind an expandable source-material section.
- Renamed Saved Reports to Report Library.
- Made report list cards easier to scan with report type, date, confidence, and source count.
- Reworked report details so the report body is the main content.
- Moved report focus fields, citations, metadata, guardrail status, timestamps, and disclaimer version behind expandable sections.
- Changed the report regenerate action label to Refresh Report.
- Kept the financial disclaimer visible in a lighter reading-friendly format.

## User Experience

The default report and briefing experience should now answer:

- What is the report saying?
- When was it retrieved?
- How confident is it?
- How many sources support it?

The user can still open details to inspect:

- citations
- raw source material
- report metadata
- focus domains
- tickers
- companies
- guardrail status

## Handoff

- Milestone 6.5 should make source/API status language clearer.
- Phase 7 should continue improving the quality and coverage of the underlying source data.
- Phase 8 should improve flexible retrieval when the report does not have enough local evidence.
