# Milestone 6.2: Personalization Profile

Status: Complete

## Goal

Let the user tell InvestorAgent what they care about once, so future screens and agents can become less manual.

This milestone focuses on the visible profile experience. It does not yet change the full backend routing logic. That deeper routing work belongs to Milestone 6.3.

## Implemented Changes

- Added a Personalization section to Settings.
- Added editable fields for:
  - default location
  - preferred briefing time
  - watchlist tickers
  - companies of interest
  - topics to prioritize
  - housing interests
  - macro interests
  - topics to ignore
  - briefing style
- Stored the profile locally in the browser.
- Added a saved profile summary so the user can confirm what InvestorAgent remembers.
- Used the saved profile to personalize Dashboard quick questions.
- Used the saved watchlist/company fields to prefill existing agent and company-report defaults.

## User Experience

The user fills this out in Settings. They should not need to edit environment files, API keys, or backend configuration for this milestone.

Example profile:

- Location: Phoenix, AZ
- Watchlist: AAPL, MSFT, SPY, QQQ
- Companies: Apple, Nvidia, Tesla
- Priority topics: Markets, Housing, U.S. economy
- Housing interests: Mortgage rates, Affordability
- Macro interests: Inflation, Interest rates, Fed policy
- Ignored topics: crypto, small caps
- Briefing style: Balanced

## Product Behavior

After saving personalization, the Dashboard can show more relevant quick questions, such as:

- What matters for AAPL, MSFT, SPY today?
- How are rates affecting housing in Phoenix, AZ?
- What changed with Apple, Nvidia, Tesla this week?

## Handoff

- Milestone 6.3 should use these preferences in the one-question workflow.
- Milestone 6.3 should infer intent, domains, tickers, companies, region, and time window from the question plus the saved profile.
- Later phases should persist personalization in the backend if multi-device support or packaged desktop sync becomes important.
