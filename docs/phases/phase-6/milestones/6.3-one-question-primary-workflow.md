# Milestone 6.3: One-Question Primary Workflow

Status: Complete

## Goal

Make the normal user workflow feel like asking a smart assistant, not configuring a research form.

The user should usually type only one question. InvestorAgent should infer the intent, source domain, tickers, companies, location, and time window from the question and the saved personalization profile.

## Implemented Changes

- Added a primary question box directly on the Dashboard.
- Submitting the Dashboard question sends the user into Agent Chat and runs the query.
- Added deterministic context inference for:
  - intent
  - source domain
  - tickers
  - companies from saved personalization
  - location/state
  - time window
- Added a plain-language "InvestorAgent understood this as" panel.
- Hid manual intent, ticker, and domain controls under Advanced.
- Added an Advanced override mode for users who intentionally want to steer routing.
- Added a "Return To Auto" action after manual overrides.
- Kept the financial disclaimer visible in the answer area.

## Inference Behavior

InvestorAgent now infers context from questions like:

- "What are mortgage rates doing in AZ?"
- "What matters for my watchlist today?"
- "What changed with AAPL this week?"
- "How are rates affecting housing in my area?"
- "Give me a daily briefing."

The current inference is rule-based and predictable. This keeps routing understandable while the broader flexible retrieval system is still planned for Phase 8.

## Handoff

- Phase 7 should improve data coverage for regional housing and source-specific gaps.
- Phase 8 should make the agents more flexible when local evidence is missing or stale.
- Phase 8 should allow approved live retrieval while preserving citations and guardrails.
