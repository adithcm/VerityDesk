# Milestone 6.5: Source/API Status UX

Status: Complete

## Goal

Make source and API status understandable without requiring the user to know backend ingestion terminology.

The Sources page should explain what is working, what needs a key, what is scaffolded only, and what is planned for Phase 7.

## Implemented Changes

- Reworked the Sources table columns to show:
  - source
  - user-facing status
  - what the status means
  - last updated
  - latest item
- Added plain status labels:
  - Working
  - Missing API key
  - Parser not implemented
  - Scaffolded only
  - Stale
  - Failed
  - Skipped
  - Not checked
- Added next-step guidance for each source status.
- Hid technical error text behind an expandable "Technical message" section.
- Reworded access methods into clearer labels like News feed, Direct API, Dataset download, and Feed or webpage.

## Important Boundary

This milestone improves how source status is shown to the user. It does not complete missing source connectors, parsers, or extra API integrations.

Those source-data fixes are planned for Phase 7.

## Handoff To Phase 7

Phase 7 should:

- complete scaffolded source connectors
- add missing parsers
- finish dataset download handling
- expand direct API coverage where useful
- improve regional housing support
- clean up source and series labels where raw identifiers are still confusing
