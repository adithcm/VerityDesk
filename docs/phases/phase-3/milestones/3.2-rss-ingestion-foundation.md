# Milestone 3.2: RSS Ingestion Foundation

Status: Complete

## Goal

Fetch public RSS/Atom feeds from configured sources, normalize entries, store article metadata, and update ingestion run and source health records.

## Included

- RSS/Atom ingestion service.
- Public feed configuration for BBC News RSS and SEC EDGAR latest filings Atom feed.
- Feed fetching with InvestorAgent user-agent headers.
- RSS item parsing.
- Atom entry parsing.
- Normalized feed entry object.
- Article upsert by external ID, URL, or canonical URL.
- Content hash generation.
- Snapshot logging for each retrieved article entry.
- External ID tracking for source-specific feed IDs.
- Ingestion run logging with seen, inserted, updated, skipped, success, and failure counts.
- Source health updates for fresh/failed status, latest item, failure count, and stale-after timestamp.
- Local command: `make rss-ingest`.
- Tests for parsing, persistence, duplicate handling, run logging, and failure health updates.

## Source Access

This milestone uses public RSS/Atom feed access only. It does not require API keys.

Default configured feeds:

- BBC News RSS: `https://feeds.bbci.co.uk/news/rss.xml`
- SEC EDGAR latest filings: `https://www.sec.gov/cgi-bin/browse-edgar?action=getcurrent&output=atom`

## Not Included Yet

- Scheduler automation.
- Backend ingestion endpoint.
- Frontend ingestion controls.
- Official API/dataset ingestion.
- Full-text article scraping.
- LLM summarization over ingested items.

Those are covered by later Phase 3 and Phase 4 milestones.

## Definition Of Done

- RSS and Atom entries can be parsed into one normalized shape.
- Article metadata is persisted without requiring full-text storage.
- Duplicate feed entries update existing articles instead of creating duplicate article rows.
- Ingestion runs and source health records are updated for success and failure cases.
- Backend tests and lint pass.
