## Notes

- The scheduler config currently defaults to disabled, `08:00`, `local`, and `all`.
- The UI should make that state visible in plain language, for example `Daily run: Off`, `Scheduled time: 8:00 AM local`, and `Last run`.
- Latest item lists should label retrieval timestamps explicitly as `Retrieved At` so users know when the app captured each item.
- This milestone should verify the manual ingestion run flow from the UI and document what remains before automatic daily background execution is enabled.

## Remaining Gaps

- Automatic daily background execution is not active yet.
- Schedule config is in memory and should be persisted before exposing editable scheduler settings as durable app preferences.
- Census, FHFA, and Freddie Mac connectors are scaffolded but still return skipped placeholder results.
- Optional providers such as Alpha Vantage, Finnhub, NewsAPI, and GDELT remain unavailable until API keys and connector implementations are added.

## Later Phase Handoff

- Phase 4 should use the current working ingestion outputs for agent routing, citations, risk framing, and source-aware answers.
- Phase 5 should improve research output quality by turning raw ingested records into cited briefings and reports.
- Phase 5 should clean up economic observation display, including replacing raw FRED series IDs such as `UNRATE`, `FEDFUNDS`, and `MORTGAGE30US` with user-friendly indicator names.
- Phase 5 should group repeated economic observations so the dashboard and briefings do not show a wall of near-identical rows from the same series.
- Phase 5 should separate article/news items from economic data points in generated briefings and source panels.
- Phase 5 should finish the scaffolded official-source connectors for Census Economic Indicators, FHFA House Price Index, and Freddie Mac PMMS.
