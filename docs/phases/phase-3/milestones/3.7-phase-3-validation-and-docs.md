# Milestone 3.7: Phase 3 Validation And Docs

Status: Planned

## Goal

Run the full Phase 3 validation pass, document remaining gaps, and prepare Phase 3 for merge.

## Expected Deliverables

- Frontend scheduler status card showing whether daily runs are on, scheduled time, run mode, and last run.
- Clearer ingestion timestamp labels in the UI, including `Retrieved At` for latest items.
- End-to-end local run checklist.
- Backend and frontend validation checklist.
- Source freshness review using current ingestion health data.
- Known limitations and next-phase handoff.
- Phase 3 completion status update.

## Notes

- The scheduler config currently defaults to disabled, `08:00`, `local`, and `all`.
- The UI should make that state visible in plain language, for example `Daily run: Off`, `Scheduled time: 8:00 AM local`, and `Last run`.
- Latest item lists should label retrieval timestamps explicitly as `Retrieved At` so users know when the app captured each item.
- This milestone should verify the manual ingestion run flow from the UI and document what remains before automatic daily background execution is enabled.
