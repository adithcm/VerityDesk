# 9.6.4 Visual Module Data API

Status: Planned

## Goal

Create backend data for the Home visuals and drill-downs using structured API/source data instead of report text alone.

## Scope

- Add endpoint(s) for visual modules.
- Build module data from existing stored sources and API connectors.
- Include chart points, source freshness, and source timestamps.
- Support missing/stale/source-not-connected states.

## Initial Modules

- Housing:
  - mortgage rates
  - FHFA/home price trend
  - affordability proxy
  - local/regional status when available
- Markets:
  - index/watchlist proxy
  - rates/yields context
  - sector or volatility proxy when available
- Companies:
  - watchlist news/catalyst count
  - SEC filing count
  - recent company-source freshness
- Macro:
  - FRED/Census observations
  - rates/labor/inflation/credit indicators where available

## Deliverables

- Visual module response schema.
- Backend service for module construction.
- API tests for module responses.
- Frontend fetch hook/state model.

## Manual Steps

None expected if current API keys remain configured.

## Validation

- Endpoint returns usable modules with current stored data.
- Missing data produces clear UI states instead of fake certainty.
