# 9.6.6 Daily Brief Page

Status: Planned

## Goal

Make Daily Brief a dedicated autogenerated markdown-style AI briefing page.

## Scope

- Add/replace Daily Brief page.
- Use saved profile and daily generated report data.
- Include Tavily/live web context.
- Include connected API metrics and source freshness.
- Include watch item alerts/quiet states.
- Hide citations by default.

## Brief Sections

- `## Bottom Line`
- `## What Changed`
- `## Major Trends`
- `## Why It Matters To You`
- `## What To Watch`
- `## Confidence And Gaps`

## Deliverables

- Daily Brief UI.
- Markdown rendering with compact formatting.
- Hidden sources drawer.
- Refresh/regenerate action.

## Manual Steps

None expected.

## Validation

- Daily Brief reads like a concise AI briefing, not a raw data page.
- Sources are available but not visually overwhelming.
