# 9.6.6 Daily Brief Page

Status: Complete

## Goal

Make Daily Brief a dedicated autogenerated markdown-style AI briefing page.

## Scope

- Add/replace Daily Brief page.
- Use saved profile and daily generated report data.
- Include Tavily/live web context.
- Include connected API metrics and source freshness.
- Include watch item alerts/quiet states.
- Hide citations by default.

## Brief Sections

- `## Bottom Line`
- `## What Changed`
- `## Major Trends`
- `## Why It Matters To You`
- `## What To Watch`
- `## Confidence And Gaps`

## Deliverables

- Daily Brief UI updated to the dark Option M visual direction.
- Markdown rendering with compact formatting.
- Hidden sources/citations drawer.
- Refresh/regenerate action.
- Latest saved daily briefing appears when available, not only reports generated in the current session.

## Implementation Notes

- Daily Brief uses the current generated report first, then falls back to the latest saved `daily_briefing` report.
- Source material and citations remain collapsed by default.
- The page avoids old white-card styling in the primary Daily Brief flow.

## Manual Steps

None expected.

## Validation

- Daily Brief reads like a concise AI briefing, not a raw data page.
- Sources are available but not visually overwhelming.
