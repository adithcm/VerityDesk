# 9.6.2 Login And Setup Flow

Status: Complete

## Goal

Add an official-looking entry flow before the app opens to Home.

## Scope

- Add Login screen.
- Add first-time Setup process.
- Keep implementation local-first for now.
- Capture user profile details needed for personalization.
- Route completed setup into Home.

## Setup Should Collect

- profile name
- location and housing markets
- watchlist tickers and companies
- sectors and important topics
- personal note/goals
- answer style preference
- daily brief schedule
- source/API status overview

## Deliverables

- Login/setup UI added as the official app entry point.
- Local profile persistence reused from the existing personalization profile.
- First-run flow detection now checks a local session and setup completion.
- Ability to reopen setup from Settings remains available.
- Deployment path documented for backend user tables tied to real login.

## Implementation Notes

- The current build uses `investoragent.localSession.v1` in local storage as a lightweight desktop session marker.
- The setup profile continues to use `investoragent.personalization.v1`.
- Real authentication is intentionally deferred until deployment architecture is chosen.
- Future backend storage should persist profile, settings, saved chats, daily brief preferences, source configuration, watch items, and acknowledgement state per user.

## Manual Steps

None expected unless a future real auth provider is chosen.

## Validation

- First-time user sees setup.
- Returning user opens to Home.
- Setup data appears in Settings and agent/profile context.
