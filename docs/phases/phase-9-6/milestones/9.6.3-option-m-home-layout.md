# 9.6.3 Option M Home Layout

Status: Complete

## Goal

Replace the current busy dashboard with the selected Option M Home layout.

## Scope

- Implement the liquid-console Home layout.
- Reduce top-level navigation to:
  - Home
  - Daily Brief
  - Agent Chat
  - Settings
- Add left rail profile/status area.
- Add visual modules:
  - Daily Read
  - Housing
  - Markets
  - Companies
  - Macro
- Keep one main ask bar.
- Move operational clutter away from Home.

## Deliverables

- Option M Home shell implemented in the app.
- Visible top-level navigation reduced to Home, Daily Brief, Agent Chat, and Settings.
- Visual-first module grid added for Daily Read, Housing, Markets, Companies, and Macro.
- Home ask behavior routes into Agent Chat.
- Compact status/profile rail added on Home.

## Implementation Notes

- Home modules currently derive from existing reports, source health, schedule state, and saved profile fields.
- A dedicated backend visual module endpoint is still planned for 9.6.4.
- Reports, Sources, and Watchlist are no longer visible as top-level tabs, but their existing pages remain internally available until Settings consolidation in 9.6.8.

## Manual Steps

None expected.

## Validation

- Home has fewer visible tabs and less text.
- No old white-page styling remains in the default flow.
- Asking from Home opens/focuses Agent Chat.
