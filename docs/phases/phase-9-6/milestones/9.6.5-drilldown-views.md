# 9.6.5 Visual Drill-Down Views

Status: Complete

## Goal

Let users click Home visuals to see deeper source/API stats.

## Scope

- Add drill-down route/state for each visual module.
- Show larger charts and key stats.
- Show source timestamps and source freshness.
- Keep detailed citations/source rows collapsed by default.
- Add `Ask About This`.
- Add optional `Add To Daily Brief`.

## Deliverables

- Drill-down UI added inside Home.
- Chart/stat components reusable by module type.
- Context payload for `Ask About This` added.
- Empty/stale states for missing data.
- Source rows remain collapsed by default.

## Implementation Notes

- Clicking any Home visual opens a focused panel with a larger chart, key stats, primary signal, timestamp, and source detail drawer.
- `Ask About This` opens Agent Chat and pre-fills the question with visual status, primary signal, stats, sources, and the module's suggested prompt.
- The drill-down uses backend visual API data when available and the local fallback visual shape when the backend is unavailable.

## Manual Steps

None expected.

## Validation

- Clicking Housing, Markets, Companies, and Macro opens a focused view.
- `Ask About This` opens Agent Chat with visual context attached.
