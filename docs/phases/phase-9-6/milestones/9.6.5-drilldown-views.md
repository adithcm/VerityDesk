# 9.6.5 Visual Drill-Down Views

Status: Planned

## Goal

Let users click Home visuals to see deeper source/API stats.

## Scope

- Add drill-down route/state for each visual module.
- Show larger charts and key stats.
- Show source timestamps and source freshness.
- Keep detailed citations/source rows collapsed by default.
- Add `Ask About This`.
- Add optional `Add To Daily Brief`.

## Deliverables

- Drill-down UI.
- Chart/stat components reusable by module type.
- Context payload for `Ask About This`.
- Empty/stale states for missing data.

## Manual Steps

None expected.

## Validation

- Clicking Housing, Markets, Companies, and Macro opens a focused view.
- `Ask About This` opens Agent Chat with visual context attached.
