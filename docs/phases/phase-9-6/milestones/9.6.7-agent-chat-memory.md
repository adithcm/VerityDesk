# 9.6.7 Agent Chat With Session Memory

Status: Complete

## Goal

Make Agent Chat feel like ChatGPT/Codex with active and previous chats visible together.

## Scope

- Add Agent Chat page based on Option M mockup.
- Show active chat and previous chats in the same page.
- Add `New Chat`.
- Persist sessions and messages.
- Load previous sessions with summary/context.
- Pass session memory into agent requests.
- Support visual-context messages from drill-downs.

## Deliverables

- Local chat session data model.
- Previous-session sidebar in Agent Chat.
- `New Chat` and previous-chat selection.
- Compact session memory included in agent request context.
- Visual drill-down context appears in the active chat when using `Ask About This`.

## Implementation Notes

- Session memory is local-first for this milestone using browser local storage.
- The active session and previous chats are visible on the same page.
- A compact recent-message prefix is included with agent requests until backend chat tables and a dedicated memory field are added during auth/deployment work.

## Manual Steps

None expected.

## Validation

- User can create a new chat.
- User can select a previous chat.
- Agent response uses active session context.
- Visual drill-down context appears in chat when using `Ask About This`.
