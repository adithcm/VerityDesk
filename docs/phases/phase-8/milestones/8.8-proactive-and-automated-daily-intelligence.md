# Milestone 8.8: Proactive And Automated Daily Intelligence

Status: Complete

## Goal

Make the daily briefing and proactive suggestions use the new web-first, personalized research flow.

The app should feel less like a generic report generator and more like a daily intelligence assistant that already knows the user's watchlist, preferred regions, and source preferences.

## What Changed

- Daily briefings now read saved preferences before building the agent request.
- Daily briefing prompts now explicitly tell the research flow to:
  - use Tavily live web research as the primary current source
  - use direct APIs and local stored data as verification/context
  - focus on the user's saved watchlist
  - focus on the user's saved regions
  - keep the briefing concise and high signal
- Daily briefing reports now save personalization metadata:
  - watchlist tickers used
  - regions used
  - enabled sources used
  - whether the report was personalized
- Scheduled automatic daily briefings inherit this behavior because the scheduler calls `generate_daily_briefing`.
- Explicit regions from the user still override saved preferred regions.
- Proactive suggestions already use saved preferences from Milestone 8.7 and now align with the personalized daily briefing behavior.

## Intended Behavior

If saved preferences are:

```text
Watchlist: AAPL, MSFT
Preferred region: Arizona
Enabled sources: newsapi, fred-api
```

Then a manual or scheduled daily briefing should automatically ask the agent for a Tavily-first briefing focused on:

- broad world/market/macro/company/housing signals
- AAPL and MSFT
- Arizona
- configured supporting sources

The user should not have to type that every morning.

## Manual Step

No new API keys are needed.

For full live-web behavior, Tavily still needs to be configured:

```bash
TAVILY_API_KEY=your-key-here
LIVE_WEB_SEARCH_PROVIDER=tavily
```

## Tests Added Or Updated

- Daily briefing uses saved watchlist, preferred regions, and enabled sources.
- Daily briefing prompt tells the agent to use Tavily live web research first.
- Daily briefing stores personalization context in report metadata.
- Explicit regions override saved preferred regions.

## Handoff To 8.9

Milestone 8.9 should validate the whole Phase 8 flow against flexible real-world questions and update the final docs. It should include checks for web-first behavior, personalization, citations, guardrails, and graceful fallback when any external provider is unavailable.
