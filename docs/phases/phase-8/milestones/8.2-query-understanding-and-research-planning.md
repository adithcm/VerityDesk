# Milestone 8.2: Query Understanding And Research Planning

Status: Complete

## Goal

Turn a natural-language user question into a structured research plan before any retrieval work runs. This milestone makes the backend infer what the user likely means instead of depending on dropdowns, manual source selection, or frontend-only guesses.

## Implemented

- Added structured query understanding to `ResearchWorkflowPlan`.
- Added `QueryUnderstanding` fields for:
  - inferred intent
  - topics
  - domains
  - tickers
  - companies
  - regions
  - sectors
  - time window
  - freshness need
  - answer style
  - whether live web research is required
- Added backend inference for common company aliases and ticker symbols.
- Added topic/domain inference for housing, markets, macro, company, world news, technology, energy, and banking.
- Added sector inference for technology, energy, financials, real estate, consumer, and healthcare.
- Added time-window inference for current, weekly, monthly, quarterly, yearly, and historical questions.
- Added planner search-query generation for:
  - the original question
  - topic/region live web searches
  - company/ticker investor-relations and news searches
- Updated the planner so broad, current, regional, news, and under-specified questions prefer live web research first.
- Kept direct APIs and local cache in the plan as supporting/verification evidence.

## Example

User asks:

```text
What is happening with Arizona housing right now?
```

Planner should infer:

- intent: housing and macro research
- topics: housing and markets
- region: Arizona plus U.S. context
- freshness: current
- live web: required
- direct APIs: FHFA, Freddie Mac, FRED, Census, NewsAPI
- local cache: prior ingested observations and articles
- specialists: HousingAgent and related market/macro agents

## Manual Steps

No manual setup is required for Milestone 8.2.

No new API keys are needed yet. Live web execution and any optional search-provider setup are expected in Milestone 8.3.

## What This Does Not Implement Yet

- Actual web search execution.
- Browser-like page retrieval.
- Source allowlist/blocklist enforcement.
- Evidence fusion ranking from real web results.
- Rebuilt prompts for final answer style.
- UI simplification.

## Validation

Added tests for:

- current regional questions prioritizing live web research
- company/ticker inference from questions like Apple and Nvidia
- sector/topic inference for AI/chip market questions
- direct API support for structured housing/mortgage questions
- ordered workflow steps
- explicit source override behavior

## Handoff To 8.3

Milestone 8.3 should implement the actual controlled live web research tool. It should consume the `QueryUnderstanding` and `ResearchWorkflowPlan` objects created here, execute approved web searches, extract cited evidence, and enforce source-quality rules.
