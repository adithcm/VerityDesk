# Milestone 8.6: Clean LLM Answer Synthesis

Status: Complete

## Goal

Make the final answer feel like a useful research response instead of a transcript of internal agent work.

The agent framework now has web-first retrieval and shared evidence packets. This milestone cleans the user-facing wording so the person sees the answer, not the plumbing.

## What Changed

- Removed coordinator routing text from the main answer body.
- Stopped dumping raw specialist risks and source-path debug notes into the visible summary.
- Kept citations and guardrails in the answer.
- Added a short `What To Watch` section instead of a long raw risk list.
- Changed synthesis instructions so the LLM:
  - answers directly first
  - uses fused evidence before specialist summaries
  - avoids internal agent names
  - avoids retrieval/debug wording
  - explains uncertainty simply
  - preserves no-buy/sell/hold guardrails
- Improved the template fallback for `SynthesisAgent` so no-OpenAI or fallback mode is cleaner too.

## Intended Behavior

The answer should now read more like:

1. Short disclaimer.
2. Direct answer in natural language.
3. A small `What To Watch` section.
4. Sources.

It should not lead with:

- `Coordinator selected...`
- `Source path...`
- raw retrieval status logs
- raw specialist agent summaries
- long internal risk/fallback lists

## Tests Added Or Updated

- Endpoint response no longer exposes coordinator routing text in the summary.
- Synthesis keeps the answer guarded while avoiding internal routing labels.
- Packet-backed synthesis includes the answer evidence but avoids raw internal trace text.
- Existing citation and guardrail tests still pass.

## Handoff To 8.7

Milestone 8.7 should personalize the research flow. The app should use saved regions, watchlists, preferences, goals, and briefing style to infer what the user likely cares about, without requiring repeated manual typing.
