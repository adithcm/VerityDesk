# Milestone 8.7: Personalization-Aware Research

Status: Complete

## Goal

Let the app use saved user preferences so the user does not have to repeatedly type the same watchlist, region, or source choices.

This supports the product direction that the app should already know what the user likely cares about, especially for broad questions like "what should I watch today?" or "what is happening with housing?"

## What Changed

- Added a user preferences API:
  - `GET /api/v1/preferences`
  - `PUT /api/v1/preferences`
- Added a preference contract for:
  - watchlist tickers
  - preferred regions
  - enabled sources
- Added a personalization service that enriches agent requests before planning.
- Added saved watchlist tickers to broad market/general/daily briefing questions when the user did not provide explicit tickers.
- Added saved preferred regions to housing/daily briefing/local questions when the user did not provide explicit regions.
- Added saved enabled sources to agent requests when the user did not explicitly choose sources.
- Kept explicit user input higher priority than saved preferences.
- Updated proactive suggestions so saved watchlists and regions shape suggested questions and reports.

## Intended Behavior

If saved preferences are:

```text
Watchlist: AAPL, MSFT
Preferred region: Arizona
Enabled sources: newsapi, fred-api
```

Then:

- "What should I watch today?" can automatically include AAPL/MSFT and preferred sources.
- "What is happening with housing?" can automatically include Arizona.
- "What is happening with Tesla in Texas?" keeps Tesla/Texas and does not override them with saved preferences.
- Daily briefing generation can use saved context through the normal agent query flow.

## Manual Step

No new external API keys are needed.

The current milestone adds the backend preference API. A cleaner frontend preference editor belongs in the later UI cleanup phase, but the backend is ready for it.

## Tests Added

- Preferences can be created, read, updated, normalized, and deduped.
- Broad questions receive saved watchlist/source context.
- Housing questions receive saved region context.
- Explicit user-supplied tickers and regions are not overwritten.
- Preference API round trip works.
- Proactive suggestions use saved watchlist and region preferences.

## Handoff To 8.8

Milestone 8.8 should use this personalization layer for proactive and automated daily intelligence. Daily briefings should feel tailored to the user's saved interests, not generic.
