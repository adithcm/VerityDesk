# Milestone 2.6: Frontend Shell

Status: Complete

## Goal

Create the first usable frontend workspace for the local InvestorAgent app and connect it to the Phase 2 backend contracts.

## Included

- App shell with primary navigation.
- Dashboard view with source metrics and domain status.
- Daily Briefing scaffold.
- Sources view connected to `GET /api/v1/sources`.
- Watchlist scaffold.
- Agent Chat view connected to `POST /api/v1/agents/query`.
- Settings scaffold showing local runtime configuration.
- Visible financial disclaimer in the app shell and agent response surface.
- Basic loading, empty, and error states for connected backend calls.

## Not Included Yet

- Live article ingestion.
- Real daily briefing generation.
- Editable watchlists.
- Persisted settings.
- Production-grade UI polish.
- Desktop packaging.

These belong in later ingestion, research output, full UI, desktop app, and portable deployment phases.

## Definition Of Done

- Frontend has the six core Phase 2 screens.
- Source catalog data loads from the backend when the backend is running.
- Agent Chat can submit a research request and render the structured placeholder response.
- Strategy-oriented surfaces show the financial disclaimer.
- Frontend typecheck and production build pass.
