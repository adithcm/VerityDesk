# Milestone 2.5: Agent And Guardrail Contracts

Status: Complete

## Goal

Define the first backend contracts for agent requests, structured research responses, citations, confidence, risks, and investment guardrails.

## Included

- `AgentQueryRequest` schema for user query, intent, domains, tickers, companies, regions, source filters, and safety level.
- `AgentQueryResponse` schema for summary, agents run, claims, citations, confidence, risks, follow-up questions, and guardrail status.
- Claim, citation, confidence, and guardrail schema objects.
- Placeholder `CoordinatorAgent` service that returns a structured response without live ingestion.
- Guardrail service with required financial disclaimer text.
- Basic detection for direct advice phrases such as buy/sell/hold instructions and guaranteed-return language.
- `POST /api/v1/agents/query` endpoint.
- Tests for endpoint contract validation and guardrail behavior.

## Endpoint

`POST /api/v1/agents/query`

The endpoint accepts a structured research request and returns a placeholder agent response using the same shape future real agents will use.

## Not Included Yet

- Live article retrieval.
- Direct source APIs.
- LLM orchestration.
- True multi-agent execution.
- Persisted agent runs.
- Citation validation against retrieved content.

These belong in later ingestion, agent framework, and research output phases.

## Definition Of Done

- Backend exposes a stable agent query contract.
- Investment-oriented responses include the required disclaimer.
- Direct investment advice phrasing is flagged by guardrails.
- Placeholder agent output is safe, structured, and covered by tests.
