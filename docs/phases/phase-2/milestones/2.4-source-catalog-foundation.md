# Phase 2 Milestone 2.4: Source Catalog Foundation

Status: Complete

## Goal

Add the static v1 source catalog and expose it through the backend API.

## Included In This Milestone

- Static catalog data in `backend/app/data/source_catalog.json`.
- Source catalog Pydantic schemas.
- Source catalog loader and validator service.
- `GET /api/v1/sources` endpoint.
- Filtering support:
  - `enabled_only`
  - `include_optional`
- Seed entries for:
  - BBC News RSS
  - SEC data APIs
  - SEC EDGAR RSS
  - FRED API
  - U.S. Census Economic Indicators
  - FHFA House Price Index
  - Freddie Mac PMMS
  - Company Investor Relations Pages
  - Alpha Vantage
  - Finnhub
  - NewsAPI
  - GDELT Cloud
- Tests for source loading, duplicate ID validation, endpoint response shape, and filters.
- Backend package data configuration so the catalog ships with the backend package.

## Source Metadata Fields

Each source has:

- `id`
- `name`
- `base_url`
- `source_type`
- `domains`
- `access_method`
- `requires_api_key`
- `requires_license`
- `allows_full_text_storage`
- `allows_redistribution`
- `storage_policy`
- `update_cadence`
- `reliability_tier`
- `enabled_by_default`
- `phase`
- `status`
- `notes`

## Storage Policies

- `metadata_only`: store source name, URL, title, timestamps, and article metadata.
- `metadata_and_excerpt`: store metadata plus short excerpts or summaries.
- `metadata_and_structured_values`: store metadata and structured data returned by the API.
- `structured_data`: store official structured datasets or filings metadata.

## Not Included Yet

- Persisting the catalog into SQLite.
- Source manager write/update endpoints.
- Live API or RSS ingestion.
- Source health checks.
- API key validation.

## Endpoint

List all configured sources:

```bash
curl http://localhost:8000/api/v1/sources
```

List enabled v1 sources only:

```bash
curl "http://localhost:8000/api/v1/sources?enabled_only=true&include_optional=false"
```

## Definition Of Done

- Source catalog config exists.
- Source schemas exist.
- Catalog service loads and validates sources.
- `GET /api/v1/sources` works.
- Endpoint filters work.
- Tests pass.
- Backend lint passes.
- Docs are updated.
