# Milestone 9.5.4: Markdown Answer Rendering

Status: Complete

## Purpose

Make responses easier to read and scan.

The user asked for clearer answers with headers, bolded key terms, and a Markdown-style format instead of long plain-text blocks.

## Implemented Behavior

- Backend synthesis prompts now request concise Markdown.
- Template fallback synthesis now returns Markdown headings and short bullets.
- Frontend answer areas render:
  - `##` headings
  - bold `**key terms**`
  - short bullet lines
- Main chatbot answers use the renderer.
- Saved report previews and report reading panels use the renderer.
- Daily briefing previews use the renderer.
- Hidden evidence drawers remain separate from the main answer.

## Answer Shape

Preferred response structure:

- `## Bottom Line`
- `## What Changed`
- `## Major Trends`
- `## Why It Matters To You`
- `## What To Watch`
- `## Confidence And Gaps`

## No Manual User Step

No new package, API key, or account setup is required.

## Validation

- `make backend-test`
- `make frontend-typecheck`
- `make frontend-build`
