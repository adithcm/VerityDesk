# Milestone 9.5.2: Setup And Profile Flow

Status: Complete

## Purpose

Add a simple first-time setup flow so VerityDesk can collect the user's local profile before the app becomes a daily briefing product.

## Implemented Behavior

- First-time users see a setup overlay.
- Setup can also be reopened from Settings.
- The flow saves a local profile in browser storage.
- The profile captures:
  - profile name
  - primary location
  - housing markets
  - watchlist
  - companies
  - sectors
  - personal note
  - priority topics
  - housing interests
  - macro interests
  - briefing style
  - briefing time
- The setup screen shows a simple local system check:
  - source status
  - daily run status
  - briefing time
- The setup copy explains that this is local-first and that full cloud login/sync can be added later if needed.

## No Manual User Step

No API keys, accounts, or cloud auth setup are required for this milestone.

## Product Decision

For the pre-deployment cleanup pass, "login" starts as a local profile/setup flow rather than a full hosted authentication system.

This keeps the app simple and desktop-friendly. A later cloud sync phase can add email login, multi-device accounts, or team profiles.
