# Milestone 9.5.3: Daily Topic Panel Model

Status: Complete

## Purpose

Turn preset prompt cards into daily intelligence panels that display stored responses.

The user should not feel like they are clicking hardcoded prompts. They should open VerityDesk and see the latest generated topic answers, with optional refresh controls only when they want to update a panel manually.

## Implemented Behavior

- The right-side home rail now shows `Today's Panels` instead of `Quick Briefings`.
- Panels read from saved reports rather than immediately running a hidden chatbot prompt.
- Each panel shows:
  - title
  - latest saved summary/body preview
  - last updated time
  - confidence
  - source count
  - optional refresh button
  - hidden evidence drawer when a saved report exists
- If a panel does not have a saved report yet, it shows a calm empty state and waits for refresh/daily generation.
- The daily scheduler now generates a set of daily topic reports when daily report generation is enabled:
  - Daily Briefing
  - Market Setup
  - Local Housing Pulse
  - Rates And Credit
- The existing `Report` table is reused so no database migration is needed.

## Product Impact

This moves the product closer to the desired everyday-use behavior:

1. Open app.
2. See current personalized intelligence panels.
3. Ask the chatbot only for custom follow-up questions.

## Remaining Work

Future milestones should improve the generated panel formatting, change labels, signal/noise labels, and alert/watch item behavior.

## No Manual User Step

No API keys, accounts, or external setup are required for this milestone.
