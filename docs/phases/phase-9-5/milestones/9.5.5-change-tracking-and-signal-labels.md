# 9.5.5 Change Tracking And Signal Labels

Status: Complete

## Goal

Make each daily panel easier to scan by telling the user whether the update is meaningful and how strong the evidence is.

## What Changed

- Generated reports now save lightweight panel metadata:
  - `signal_label`
  - `change_label`
  - `source_quality`
  - `previous_report_id`
  - `previous_report_as_of`
  - `citation_count`
- The app compares a newly generated report with the prior generated report of the same type.
- Daily home panels now show compact chips for signal, change, and source count.

## Labels

Signal labels:

- `High Signal`: stronger confidence with multiple supporting sources.
- `Developing`: useful current evidence, but the picture may still move.
- `Noise`: the response is mostly saying that there is no current evidence.
- `Watch Later`: source coverage or confidence is too thin to treat as important yet.

Change labels:

- `New`: no prior saved report of that type.
- `No Meaningful Change`: today's output materially overlaps with the prior saved output.
- `Improving`: the current text contains more easing or improvement signals.
- `Worsening`: the current text contains more stress or deterioration signals.
- `Mixed`: there is a change, but direction is not clearly positive or negative.

## Current Limitation

This is a lightweight heuristic layer. A future pass can make this more precise by comparing structured metrics, entity-level deltas, and source timestamps instead of mostly comparing report text.

## Manual Steps

None.
