# Milestone 10.2: Desktop Runtime Shell

Status: Complete

## Goal

Add the first Electron runtime shell for VerityDesk without changing the existing local development path.

## What Changed

- Added `desktop/` as an isolated Electron package.
- Added an Electron main process that:
  - Runs Alembic migrations.
  - Starts the FastAPI backend on `127.0.0.1:8000`.
  - Starts the Next.js frontend on `127.0.0.1:3000`.
  - Waits for both services before opening the app window.
  - Opens VerityDesk in a native desktop window.
  - Stops child processes when the app quits.
- Added a preload file with a minimal desktop runtime marker.

## Current Scope

This milestone creates a development desktop shell. It does not yet create the final packaged `.app`; that comes later in Phase 10.

## How To Try It During Development

Install desktop dependencies once:

```bash
cd desktop
npm install
```

Then run:

```bash
make desktop-dev
```

## Acceptance Criteria

- Desktop runtime files exist under `desktop/`.
- Existing `make app-dev` path remains unchanged.
- Electron shell can supervise backend/frontend processes in development mode.
