# Milestone 10.5: Production Builds

Status: In progress

## Goal

Add a production-like desktop launch path that builds the Next.js frontend first, then runs the desktop shell against the built frontend.

This is not the final macOS `.app` package. That comes in milestone 10.6.

## What Changed

- Desktop runtime supports two modes:
  - `dev`: starts `next dev`.
  - `production`: starts `next start` after the frontend has been built.
- Added Make targets:
  - `make desktop-build`
  - `make desktop-prod`
- Kept `make desktop-dev` for fast development.

## Commands

Validate desktop JavaScript:

```bash
make desktop-check
```

Build the frontend and run desktop syntax checks:

```bash
make desktop-build
```

Run Electron with the built frontend:

```bash
make desktop-prod
```

## Acceptance Criteria

- Existing dev launch path remains available.
- Production mode uses `next start`, not `next dev`.
- Build command validates that the frontend can compile before packaging work starts.
- No packaging dependency is required yet.
