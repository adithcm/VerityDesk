# Milestone 7.1: Source Status Audit

Status: Complete

## Goal

Create a clear source-by-source inventory before changing connectors or parsers.

This milestone should tell us exactly which sources are working, missing keys, scaffolded only, parser-needed, optional, or deferred.

## Scope

- Audit every source in `backend/app/data/source_catalog.json`.
- Compare catalog status against implemented ingestion code and tests.
- Identify sources that currently retrieve real data.
- Identify sources that are present but still need parser work.
- Identify optional providers that require user API keys.
- Update docs and source metadata where labels are misleading.

## Expected Output

- A status table in the milestone doc.
- A list of manual API keys needed for Phase 7.
- A list of sources that can be completed without new keys.
- A list of sources that should be deferred.
- Clear notes for confusing labels such as raw provider series IDs.
