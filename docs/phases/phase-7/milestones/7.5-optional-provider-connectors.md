# Milestone 7.5: Optional Provider Connectors

Status: Complete

## Goal

Add or complete optional market/news provider connectors while keeping missing-key behavior clean.

## Scope

- Reviewed current optional-provider scaffolding.
- Added connectors for:
  - Alpha Vantage News Sentiment
  - Alpha Vantage Top Gainers/Losers
  - Alpha Vantage Global Quote snapshots
  - Finnhub Company News
  - Finnhub Quote snapshots
  - NewsAPI Everything
  - NewsAPI Top Headlines
  - GDELT DOC article discovery
- Kept keyed providers skipped cleanly when the user has not supplied a key.
- Normalized provider output into existing article/evidence models.
- Stored only metadata, summaries, and excerpts according to the catalog storage policies.
- Kept GDELT as a no-key broad discovery source.

## Manual Inputs

No key is needed for:

- `gdelt-cloud`

Free API keys are needed to activate:

- `ALPHA_VANTAGE_API_KEY`
- `FINNHUB_API_KEY`
- `NEWSAPI_KEY`

The app starts and ingestion continues when these keys are missing. Missing keyed providers are marked skipped instead of failing the whole run.

## Provider Roles

| Provider | Role | Key Required |
| --- | --- | --- |
| GDELT DOC | Broad global article discovery for geopolitics, markets, energy, and housing/economy themes. | No |
| Alpha Vantage | Market, economy, real estate, technology, and energy news/sentiment discovery, plus top movers and quote snapshots. | Yes |
| Finnhub | Company-specific news and quote snapshots for configured North American symbols. | Yes |
| NewsAPI | General article discovery metadata plus U.S. business, technology, and general top headlines. | Yes |

## Sign-Up URLs

- Alpha Vantage free key: `https://www.alphavantage.co/support/#api-key`
- Finnhub free key: `https://finnhub.io/register`
- NewsAPI free key: `https://newsapi.org/register`
