# Milestone 7.5: Optional Provider Connectors

Status: Planned

## Goal

Add or complete optional market/news provider connectors while keeping missing-key behavior clean.

## Scope

- Review current optional-provider scaffolding.
- Add or complete connectors for:
  - Alpha Vantage
  - Finnhub
  - NewsAPI
  - GDELT
- Keep each provider disabled or skipped cleanly when the user has not supplied a key.
- Normalize provider output into existing article or structured observation models.
- Respect storage policies and provider terms.

## Manual Inputs

Some providers may require user-supplied API keys. This milestone should document exactly which keys are needed before implementation uses them.

## Tests

- Missing-key behavior for each keyed provider.
- Successful response parsing with mocked responses.
- Malformed response behavior.
- Source health status updates.

## Definition Of Done

- Optional providers either work with supplied keys or show clean missing-key/deferred states.
- No optional provider breaks local app startup when keys are absent.
