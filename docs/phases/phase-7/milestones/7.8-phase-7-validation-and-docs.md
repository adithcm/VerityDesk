## Phase 8 Handoff

Phase 8 should build on this broader evidence base by implementing:

- stronger natural-language query understanding
- automatic source and agent routing
- local-evidence-first retrieval
- controlled live web research when local/direct data is missing
- personalization-aware retrieval and proactive briefings
- simpler UI behavior with fewer manual inputs

Specific user handoff:

- The current UI still shows too much operational/source detail on the main screen.
- The agent experience should become more automatic and should require less context entry from the user.
- The app should personalize around what the user cares about and then proactively surface relevant daily information.
- The LLM/agent layer should be allowed to perform controlled web research when stored data is too thin, with citations and guardrails, instead of only saying it does not know.
- Later UI cleanup should happen after the source and live-research functionality is stable, so the final desktop app is simple and easy to digest.
