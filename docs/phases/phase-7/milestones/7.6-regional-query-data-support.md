# Milestone 7.6: Regional Query Data Support

Status: Planned

## Goal

Improve regional data handling so questions about places like Arizona, AZ, Phoenix, and Phoenix metro produce clearer answers.

## Scope

- Add region normalization for common state names, abbreviations, and metro phrases.
- Store or map region metadata where source data supports it.
- Support national-vs-state-vs-metro distinctions.
- Make reports and agents explain when only national data is available.
- Add explicit examples for Arizona and Phoenix.

## Example Questions

- What are mortgage rates in AZ?
- What are mortgage rates in Phoenix?
- How is housing affordability changing in Arizona?
- Is Phoenix housing cooling?

## Tests

- State abbreviation normalization.
- State name normalization.
- Metro phrase normalization.
- National-only fallback messaging.
- Regional evidence selection where available.

## Definition Of Done

- Regional questions are less brittle.
- Agents can use available regional evidence and clearly explain gaps.
- AZ/Phoenix examples are covered in tests or docs.
