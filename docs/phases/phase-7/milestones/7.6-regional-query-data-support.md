# Milestone 7.6: Regional Query Data Support

Status: Complete

## Goal

Improve regional data handling so questions about places like Arizona, AZ, Phoenix, and Phoenix metro produce clearer answers.

## Scope

- Added shared region normalization for all U.S. state names and abbreviations.
- Added starter metro phrase mapping for common metro areas, including Phoenix.
- Expanded local questions to include national context automatically.
- Connected backend agent context inference so plain-language questions can supply regions even when the UI does not.
- Updated frontend question submission so inferred location, companies, and time window are sent to the backend.
- Added wildcard series matching so agents can retrieve FHFA, Freddie Mac, Census, Alpha Vantage, and Finnhub series families.
- Updated HousingAgent to retrieve local FHFA data and national mortgage-rate context together.
- Improved evidence formatting so region is visible to the LLM.
- Improved labels for new FHFA, Freddie Mac, Census, Alpha Vantage, and Finnhub series prefixes.

## Example Questions

- What are mortgage rates in AZ?
- What are mortgage rates in Phoenix?
- How is housing affordability changing in Arizona?
- Is Phoenix housing cooling?
- Compare Phoenix home prices with national mortgage rates.
- How is Texas housing trending?
- What is happening in the Seattle housing market?

- Regional questions are less brittle.

## Current Coverage

- FHFA local house-price data can support state and metro housing questions after ingestion.
- Freddie Mac PMMS and FRED mortgage-rate data provide national mortgage-rate context.
- Census housing indicators provide national housing activity context.
- News sources can provide local/regional article context when articles mention the region and are ingested.
