# Milestone 7.3: FHFA Parser Completion

Status: Planned

## Goal

Complete FHFA House Price Index ingestion so housing reports can use house-price data from a credible direct source.

## Scope

- Review FHFA data access path and available file/API format.
- Implement dataset download or API parsing.
- Normalize geography, period, index value, source key, and retrieval time.
- Support national and state-level data first.
- Add metro-level support where the source format is stable and practical.

## Tests

- National record parsing.
- State record parsing.
- Metro-style record parsing where available.
- Empty dataset behavior.
- Malformed file/response behavior.
- Repeat ingestion deduplication.

## Definition Of Done

- FHFA source status reflects real parser behavior.
- Housing reports can cite house-price observations.
- Regional questions have better local/state context where FHFA data supports it.
