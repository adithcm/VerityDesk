# VerityDesk Icon

Source asset:

- `desktop/assets/veritydesk-icon.svg`

Reusable frontend copy:

- `frontend/public/veritydesk-icon.svg`

Design notes:

- Base colors match the VerityDesk interface: deep navy `#020617`, panel navy `#07111f`, cyan `#22d3ee`, lime `#a3e635`, and pink accent `#f472b6`.
- The mark avoids small text so it remains readable as a Dock icon.
- The central angular shape hints at a `V` and a desk/console surface.
- The lime signal dot represents daily intelligence updates.
- The cyan grid represents data, web search, and source-backed research.

Later Phase 10 packaging should export this SVG into macOS `.icns` sizes.
